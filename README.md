<h3>🌟 Highlighted Projects</h3>

#### [**🚀 Multi-Source Candidate Data Transformer**](https://github.com/Aswin-Hariram)
**Enterprise Candidate Data Reconciliation Engine**
Built a deterministic Node.js engine that transforms fragmented candidate information from resumes, ATS exports, recruiter notes, CSVs, GitHub, and LinkedIn into a single canonical profile. The system resolves conflicting data using configurable reconciliation rules without relying on LLMs, making it perfect for secure enterprise workflows.
* **Tech Stack:** Node.js, TypeScript, Express, Jest, Docker

#### [**🤖 AI Interview Platform**](https://github.com/Aswin-Hariram)
**AI-Powered Recruitment & Assessment Platform**
A full-stack recruitment platform automating candidate evaluation. It dynamically performs resume analysis, GitHub/LinkedIn profile screening, and coding evaluations, generating personalized interview questions to accelerate hiring decisions.
* **Tech Stack:** React, Tailwind CSS, Node.js, Express, Firebase, AWS, Gemini AI

#### [**☁️ EzMark**](https://github.com/Aswinhariram-skct/EzMark.git)
**Cloud-Native Smart Attendance System**
A secure, mobile-first platform leveraging cloud verification to eliminate proxy attendance. Integrated AWS Rekognition for facial identity verification, Amazon S3 for secure storage, and Firebase for real-time OTP-based attendance workflows.
* **Tech Stack:** React Native, Expo, AWS Rekognition, Amazon S3, Firebase Auth, Firestore, Node.js

#### [**🌐 Developer Portfolio with RAG Chatbot**](https://aswin-hariram.vercel.app/)
**Modern AI-Assisted Portfolio**
A responsive personal portfolio featuring a Retrieval-Augmented Generation (RAG) chatbot. The AI assistant answers visitor questions based exclusively on my project content and semantic document retrieval, preventing hallucinations and demonstrating complex system integration.
* **Tech Stack:** React, Tailwind CSS, Node.js, Gemini AI, Vector Embeddings, RAG, Vercel

#### [**✍️ Writezy (Web & App)**](https://github.com/Aswin-Hariram/Writezy_Web.git)
**AI Writing Assistant**
An intelligent writing tool powered by Google's Gemini models. It allows users to generate, rewrite, summarize, and structurally improve content through a clean, responsive interface utilizing specialized prompt templates and Markdown support.
* **Tech Stack:** React, React Native, Vite, Node.js, Express, Gemini AI, Tailwind CSS
